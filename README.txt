ТЦК — піксельна гра
====================

Як грати
--------
Відкрий index.html у браузері (Safari на iPhone, Chrome на Android, будь-який браузер на компʼютері).
Телефон тримай горизонтально (у портреті гра попросить повернути телефон).

* Телефон: стік — ліва частина екрана (до краю — біг); кнопки праворуч: УДАР, РИВОК, КИНУТИ, E, ВМІННЯ;
  пауза — кнопка праворуч угорі. Звук вмикається після першого дотику
  (на iPhone вимкни беззвучний режим перемикачем збоку).
* Компʼютер: WASD/стрілки — рух, Shift — біг, C/Ctrl — ривок, Пробіл — удар, E — сховатися/метро/самокат,
  Q — кинути, V — вміння, Esc/P — пауза, F — на весь екран.

На весь екран (як застосунок)
----------------------------
* iPhone (Safari): «Поділитися» → «На екран „Додому“». Гра запускатиметься без панелей Safari.
* Android (Chrome): меню ⋮ → «Додати на головний екран» / «Встановити застосунок».

Якщо гра пригальмовує: Пауза → Налаштування → Графіка: «середня» або «низька»
(за замовчуванням «авто» — гра сама знижує якість, якщо кадри повільні).

Для власника сайту
------------------
* Вміст цієї теки (або tck-game.zip) можна викласти на будь-який статичний хостинг
  (GitHub Pages, Netlify, Cloudflare Pages, власний сервер) — достатньо віддавати файли як є.
* itch.io: «Kind of project: HTML», завантажити tck-game.zip, позначити «This file will be played in the browser»,
  увімкнути «Mobile friendly» (Orientation: Landscape) і «Fullscreen button».
* Гра не завантажує нічого з інтернету: усе (графіка, звук, сирена) — в index.html.
  Прогрес зберігається в localStorage браузера.
